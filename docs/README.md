# Документация Capsule

Подробная техническая документация проекта. `CLAUDE.md` в корне — это краткая
«карта»; здесь лежат детали по каждой подсистеме.

> **Доки нужно держать актуальными.** Меняешь подсистему — обнови соответствующий
> файл в этой папке (и при необходимости `CLAUDE.md`) в том же изменении. См. раздел
> «Документация» в `CLAUDE.md`.

## Оглавление

| Файл | О чём |
| --- | --- |
| [architecture.md](architecture.md) | Поток данных через `/api/db`, zustand-стор, авторизация, роутинг, serverless |
| [data-model.md](data-model.md) | Модель Firestore (`capsule/{uid}` + подколлекции), типы, инлайн-картинки, миграции |
| [ai.md](ai.md) | Два AI-провайдера (llm7.io + Gemini), промты, фолбэки, извлечение картинки по URL |
| [photo-pipeline.md](photo-pipeline.md) | Добавление фото: классификация → коррекция → сжатие, доска гардероба |
| [deployment.md](deployment.md) | Деплой на Vercel, переменные окружения, секреты, e2e |

## Быстрый старт

```bash
npm install
npm run dev      # HTTPS dev-сервер (basic-ssl)
npm run build    # tsc -b && vite build — обязан быть зелёным перед деплоем
```

Полный набор команд — в `CLAUDE.md`.
