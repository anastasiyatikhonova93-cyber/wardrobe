# AI

В проекте два независимых AI-провайдера с разными задачами, тарифами и местом
вызова. Общий принцип для обоих: промт → JSON → извлечение через регэксп
`/\{[\s\S]*\}/` → мягкие фолбэки. **AI никогда не валит UI** — при любой ошибке
возвращается дефолт или срабатывает запасной путь.

## 1. llm7.io — текстовые задачи, из браузера

- База: `https://api.llm7.io/v1` (OpenAI-совместимый chat/completions).
- Бесплатный; ключ **фиктивный** (`VITE_LLM_API_KEY` или строка `'unused'`),
  модель `'default'`.
- Вызывается **прямо из браузера** (`src/ai.ts`, частично `src/lib/classify-photo.ts`).

Функции в `src/ai.ts`:

| Функция | Что делает | Фолбэк при сбое |
| --- | --- | --- |
| `analyzeWardrobe` | Главная: по гардеробу+профилю предлагает 3–5 докупок и 5–8 образов | бросает ошибку (ловит вызывающий UI) |
| `inferItemDetails` | По названию вещи → категория + сезоны | `{ category: 'tops', seasons: [] }` |
| `suggestColor` | Подбор цвета вещи под гардероб (1 слово на русском) | бросает ошибку |
| `generateOutfitName` | Короткое русское имя образа (2–4 слова) | `«{Сезон}: образ»` |

`analyzeWardrobe` сопоставляет имена вещей из ответа LLM с реальными `id` (поиск по
`name.toLowerCase()`), раскладывая их в `wardrobeItemIds` / `shoppingItemIds` образа.
Промт собирается из профиля (`buildProfileContext`: тип фигуры, рост, особенности
«скрыть/подчеркнуть», стили) и списков вещей (`describeItem`).

Парсинг — `extractJson`: вытаскивает первый `{...}`-блок, безопасно отдаёт
`{ suggestions: [], outfits: [] }` при невалидном JSON.

## 2. Gemini — картинки, через serverless

Ключ `GEMINI_API_KEY` живёт **только на сервере** (Vercel env). Браузер обращается к
своим эндпоинтам, а не к Google напрямую — так ключ не утекает и обходится CORS
(сервер сам тянет картинку по URL).

### `api/classify.ts` — распознавание вещи (vision)

- Модель `gemini-2.5-flash`, `responseMimeType: application/json`.
- Вход: `{ image }` (data-URL/base64) **или** `{ imageUrl }` (сервер скачивает сам,
  с фейковым `User-Agent` — иначе Wikimedia и пр. отвечают 403).
- Выход: `{ name, category, color, seasons }`.
- `callGeminiWithRetry`: до 3 попыток, ретрай на `429/500/503` (перегрузка
  бесплатного тарифа), таймаут 30 с.

### `api/detect.ts` — мульти-распознавание вещей на одном фото (vision)

- Модель **`gemini-2.5-pro`**, `responseMimeType: application/json`. Pro — потому что
  у flash рамки на плотном фото налезают друг на друга и промахиваются по мелочам
  (серьги/кольцо), из-за чего кроп захватывает соседний предмет. Pro медленнее
  (~40-50 с на одну детекцию) → таймаут Gemini 58 с, `maxDuration` функции 60 с.
- Вход: `{ image }` (data-URL/base64) **или** `{ imageUrl }`.
- Выход: `{ items: [{ label, category, color, seasons, box_2d }] }`. `box_2d` —
  рамка вещи `[ymin, xmin, ymax, xmax]` в нормировке `0..1000` (документированный
  формат Gemini, origin — верхний левый угол). Клиент (`src/lib/detect-items.ts`)
  переводит в `0..1` и вырезает каждую вещь.
- Промт жёстко требует выделять **только вещи на человеке** и игнорировать раму
  зеркала/мебель/декор/фон. `callGeminiWithRetry`: ретрай на `429/500/503`.

### `api/clean-image.ts` — AI-ретушь фото

См. подробности в [photo-pipeline.md](photo-pipeline.md). Кратко: модель
`gemini-2.5-flash-image`, `responseModalities: ['IMAGE']`, промт зависит от категории
вещи. **Требует включённого биллинга Google** — на бесплатном тарифе отдаёт 429
(квота), и клиент откатывается на локальную обработку. Здесь `429` НЕ ретраится
(квоту повтор не лечит), ретрай только на `500/503`; таймаут 90 с.
- Необязательное поле `label` в теле запроса: когда кроп содержит несколько вещей
  (мульти-распознавание `/detect-test`), название извлекаемого предмета добавляется
  в промт («извлеки ИМЕННО этот предмет, убери остальное») — иначе модель оставляет
  самый заметный объект, а не нужный. Клиент: `cleanupBest(blob, category, label)`.

## Извлечение картинки товара по ссылке — `api/og-image.ts`

Не AI, но рядом по смыслу (используется при импорте по ссылке). По `?url=` достаёт
картинку товара: сначала через `api.microlink.io`, фолбэк — прямой фетч HTML и
разбор `og:image` регэкспом. Кэш ответа `s-maxage=86400`.

## Где задаются ключи

| Ключ | Где | Назначение |
| --- | --- | --- |
| `VITE_LLM_API_KEY` | опц., клиент | llm7.io (фиктивный, можно не задавать) |
| `GEMINI_API_KEY` | Vercel env, сервер | Gemini vision (classify/detect) + image-gen |

Подробнее про окружение — в [deployment.md](deployment.md).
